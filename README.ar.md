# مصنع الوكلاء (Agent Factory)

> اسم مبدئي — لم يُحسم اسم المنتج بعد.

منصة مفتوحة المصدر تحوّل بيانات الشركة (ملفات Excel/CSV، واجهات REST، والموقع الإلكتروني)
إلى وكيل ذكاء اصطناعي يجيب **بالعربية والإنجليزية مع ذكر المصادر**، وينفّذ إجراءات معتمدة،
ويبلّغ عن الأسئلة التي لم يستطع الإجابة عنها (**حلقة الفجوات**). السوق الأول: مصر.

## الحالة
ما قبل الإصدار الأول. المواصفات في مجلد `specs/`.
